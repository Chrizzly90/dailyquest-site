## Vor der Veröffentlichung der App

Die Platzhalter `[[NAME]]`, `[[ANSCHRIFT]]`/`[[ADDRESS]]` und `[[E-MAIL]]`/`[[EMAIL]]` durch die echten Angaben ersetzen. Prüfen, ob noch welche übrig sind:

```bash
grep -rn "\[\[" --include=*.html .
```

Die Texte sind eine sorgfältige Vorlage für eine App ohne Server, Konto und Tracking. Sie sind keine Rechtsberatung. Ändern sich die Funktionen der App (z. B. iCloud-Sync), müssen sie angepasst werden.
